# Archived: prototype v0 (October 2026)

This is an early prototype that does not use SUMO. It has its own Python queue simulator, mock perception, and a React dashboard.

The team decided on 9 November 2026 **not to build on it**: it is not up to the required standard, and the new system will be built from scratch around SUMO, following the Deliverable 2 design.

Treat this folder as reference only. Do not import from it, extend it, or present it as the current system. Some small, specific ideas can be reused if they are re-implemented cleanly in the new codebase.
